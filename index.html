AI red team lab

The newest part of my work, and the part I'm learning in public. I'm exploring how AI systems fail under attack, using open-weight models that run locally, so experiments stay private and nobody else's system is on the receiving end.

  • LLM01

    How far does prompt injection get against a local model with a strict system prompt?

    Instruction overrides, role-play and encoded payloads.

  • LLM07

    What leaks when someone asks a model to repeat its instructions?

    Assume the system prompt is public, then see what that exposes.

  • LLM03

    What can a malicious model file do when you load it?

    Model weights are dependencies too: the supply chain problem, one layer down.

  • LLM06

    How much should an AI agent be allowed to do on its own?

    Least privilege for tools, the way it already applies to IAM roles.
